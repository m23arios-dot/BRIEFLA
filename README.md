# BRIEFLA

Responsywny prototyp BRIEFLA dla Polaków w Niemczech.

## Struktura GitHub

Wszystkie potrzebne pliki znajdują się bezpośrednio w jednym miejscu — bez folderu `assets` i bez dodatkowych podfolderów.

- `index.html`
- `styles.css`
- `app.js`
- `manifest.json`
- `logo.png`
- `hero-reference.png`
- `amt-illustration.svg`

## Funkcje

- Start, Kategorie, Moje pisma, Szablony i Profil
- formularz opisu sprawy po polsku
- gotowe szablony niemieckich pism
- wyszukiwanie szablonów
- kopiowanie i zapis wygenerowanego pisma
- responsywny widok desktop/mobile
